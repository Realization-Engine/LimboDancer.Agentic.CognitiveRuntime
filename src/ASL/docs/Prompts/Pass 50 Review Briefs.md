# Pass 50: the five reviews' briefs

Pass 50 (Armored combat I) is built on `feature/asl-backlog-pass-50`, cut from main at `b4ce31ef`. Its design is `src/ASL/docs/Passes/ASL Unit Backlog Pass 50 Design.md`: section 7 (a vehicle fires weapon by weapon: tasks 50.1, 50.2), section 8 (the MA while moving: 50.3), section 9 (the Target Facing from inside the target's hex: 50.6). Rulings R50.1 to R50.12 are in the design only. Sections 2, 7.1, 8.1, and 9.1 list what the pass left out against the plan and its frame: Gun Duels (50.4) and MG fire against armor (50.5) are not built at all.

## Said in every brief

- Read-only. Do not edit any file, build, run tests, start a server, or run a git command that changes state. Do not create a worktree.
- The pass is `git diff b4ce31ef..HEAD -- <path>`, run from `E:\Archive\GitHub\dlandi\LimboDancer.MCP`.
- Search with the Grep and Read tools; never `grep -r` in a shell over `src/ASL` (it walks `bin` and `obj`).
- The rulebook's page texts are in `E:\Archive\GitHub\dlandi\pass32-tools\pass35\session3\pages\pNNN.txt` (physical pages 043 to 253). A rule is read on its page file, never from memory. A rule's example is part of the rule. Quote at most one phrase of under 15 words for a finding.
- No file is written: the findings are the closing message. At most 12, most serious first, each with a grade (BLOCKER, SHOULD FIX, NOTE), the file and line, the rule and its page, what is wrong, and the smallest fix. Then one paragraph on what was read and what could not be checked.
- What the design lists as "left out", "not built", or a departure is not a finding. A finding is a case the code reaches that the rule does not cover, a case of the rule left out that the design does not list, or a plain fault.
- The catalog's armed vehicles are three: the PzKpfw IIIH (`attacker-tank`: T turret, ROF 2, BMG 3, CMG 5), the T-34 M41 (`defender-tank`: RST turret, no ROF, BMG 2, CMG 4), and the SPW 251/1 (`attacker-halftrack`: MA AAMG, ROF 1, OT). No vehicle has a tank's AAMG, a Rear MG, a Fixed-Mount BMG, a FT, Secondary Armament, or a Gyrostabilizer: a rule for one of those is not a finding.
- A fact this pass adds to a record is absent from a record made before the pass, which must still check as it was recorded. A place where an older record would now fail, or resolve differently, is a BLOCKER.

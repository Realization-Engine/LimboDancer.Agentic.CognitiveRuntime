# Map Studio fonts

These unmodified TrueType files implement the font families and weights from the supplied redesign stylesheet. CSS declarations are in `../site.css`; there is no external font stylesheet or runtime Google Fonts request.

Downloaded 2026-09-28 from the Google Fonts CSS API. Corresponding SIL Open Font License 1.1 notices are retained beside the font files.

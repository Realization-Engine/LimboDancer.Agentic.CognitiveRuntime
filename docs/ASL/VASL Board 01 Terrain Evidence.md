# VASL board 01 terrain evidence for Scenario A1

The [board 01 metadata](https://github.com/vasl-developers/vasl/blob/develop/boards/src/bd01/BoardMetadata.xml) reports board version 6.9 (Jan 2025), image `bd01.gif`, dimensions 33 by 10 hexes, and 63 explicit building-type overrides. The inventory in [vasl-board-01-building-overrides.json](SourceRegistry/vasl-board-01-building-overrides.json) extracts those overrides. Its source Git blob is `e91b0d99a7a788812444753cae245841875a8de6`. For example, E4 is a two-level stone building, P7 a one-level stone building, and F1 a one-level wooden building.

This inventory is **partial**. Absence from the overrides does not establish that a hex lacks a building: VASL uses shared image/LOS terrain defaults for other buildings. Board 01's [LOSData](https://github.com/vasl-developers/vasl/blob/develop/boards/src/bd01/LOSData) is a gzip-compressed binary asset (Git blob `8d77d26222b7bb21d8c1fdda6ba05b447f63c317`); this slice does not parse or validate it. The supplied board image is a visual cross-check, not a machine-verified terrain inventory.

`Board01ValidatedSnapshotSource` requires the exact board metadata identity, an explicitly listed building hex, ground-level location binding `bd01:<hex>:0`, and no board variant or overlay. It rejects inconsistent location identifiers and unasserted building facts; the empty-building case also requires an asserted adjacency fact. Unit identity, occupancy, phase, adjacency, movement points, modifiers, stacking, and snapshot version are supplied state variables. xUnit tests can construct these snapshots directly through `IScenarioA1BoardSnapshotSource`. The wrapper validates only the static terrain claim and does not calculate the other variables.

The supplied snapshot variables now project the seven admitted exact cases: empty building, known enemy MMC, fortified unbreached prohibition, single enemy SMC overrun attempt, breached Advance Phase attempt, friendly overstack cost, and ordinary Advance Phase entry attempt. The adapter returns no observation for concealed or unknown occupancy and for incomplete or conflicting variables. This projection uses E4's explicit ground-level building override in its conformance tests. No LOS parsing is needed for these exact cases; a new case requiring an unlisted building, LOS terrain, or a board variant must add and verify that evidence separately.
